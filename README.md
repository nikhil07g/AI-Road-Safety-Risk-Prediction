# 🚗 SafeRoute AI – Intelligent Road Safety & Risk Prediction

An AI-powered web application that analyzes uploaded road images to detect potholes, road damage, cracks, and other hazards. SafeRoute AI provides a Road Quality Score, predicts accident risks, and offers smart safety recommendations to help users make safer driving decisions.

---

## 🌟 Features

- 🔐 User Authentication (Email & Password)
- 🟢 Google Login *(Demo Only)*
- 📤 Upload Road Images
- 🤖 AI-powered Road Damage Detection
- 🕳️ Pothole & Crack Detection
- 📊 Road Quality Score
- 🚦 Traffic & Congestion Analysis
- ⚠️ Accident Risk Prediction
- 🛡️ Personalized Safety Recommendations
- 📱 Responsive User Interface

---

## 🖥️ Demo Workflow

1. Sign up using your Email & Password.
2. Login to your account.
3. *(Google Authentication is available only for demonstration purposes.)*

5. The AI analyzes the image in real time.
6. View:
   - Road Condition

   - Pothole Severity

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/your-username/AI-Road-Safety-Risk-Prediction.git
cd AI-Road-Safety-Risk-Prediction
```

### Backend

```bash
cd backend
pip install -r requirements.txt
python start_server.py
```

### Frontend

```bash
npm install
npm run dev
```
